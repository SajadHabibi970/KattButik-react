# Kattbutik React

Detta är en React-applikation där användaren kan se olika kattraser.

Appen hämtar data från The Cat API och visar kattens namn, ursprungsland och bild. Katterna visas med pagination där varje sida visar 10 katter.

## Funktioner

- Startsida med presentation av kattbutiken
- Sida med information om ägaren/kattbutiken
- Kattsida som hämtar katter från WebAPI
- Varje katt visar namn, ursprungsland och bild
- Pagination med 10 katter per sida
- Möjlighet att gå fram och tillbaka mellan listsidor

## Tekniker

- React
- JSX
- Vite
- React Router
- React Bootstrap
- The Cat API

## Starta projektet

Installera först alla paket:

```bash
npm install
```
